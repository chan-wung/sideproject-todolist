## 기술 스택

- **React 18** + **TypeScript**
- **Vite 5**
- **SCSS** (BEM 네이밍, CSS 변수 다크모드, rem 단위)
- **localStorage** 데이터 영속성 (서버 및 DB 없음)
- **PWA** (vite-plugin-pwa) — 홈 화면 설치, 오프라인 실행 지원
- **Vitest** + **Testing Library** 테스트, **ESLint** 린트
- 폰트: Pretendard, GmarketSans

## 주요 기능

- **화면 메뉴**
  - **할 일 / 주간보고** 화면 전환 — 폭 1024px 이상은 왼쪽 사이드바, 그보다 좁으면 상단 가로 메뉴 (상단 툴바는 화면 위에 고정), 사이드바는 아이콘만 보이게 접기 · 펴기 가능 (상태 유지) (주소 해시 `#/todos`, `#/report`, 새로고침·뒤로 가기 유지)

- **대시보드**
  - 이번 주 완료(지난주 비교) · 진행 중 · 밀린 일 · 오늘 마감 숫자 카드
  - 이번 주 마감인데 못 한 정기 업무 경고, 프로젝트별 완료 막대, 최근 6주 완료 수 추이, 밀린 일 목록, 이번 주 연차·휴가
  - 완료 수는 주간보고와 같은 기준으로 계산

- **캘린더**
  - 월간 달력에 마감일이 있는 할 일 · 연차·휴가 · 정기 업무를 날짜별로 표시 (칸마다 3개까지, 넘치면 `+N`)
  - 진행 중인 반복 일정의 앞날 회차를 점선 `예정`으로 표시, 날짜를 누르면 그날 목록 확인
  - `이전 달` / `다음 달` / `오늘` 이동
  - 날짜를 눌러 연차·휴가 등록: 종류 셀렉박스(연차 / 오전 반차 / 오후 반차 / 시간 연차 / 기타) + 시간 연차의 시작·종료 시각 + 사유(자유 입력)를 한 번에 등록, 보고서 모양 미리보기 (같은 날 같은 이름은 중복 불가) — 등록한 연차는 주간보고에 `날짜 + 이름 시각 (사유)`로 자동 포함

- **주간보고**
  - 한 주(월~일)에 완료한 일을 주간보고 양식으로 자동 정리: 정기 업무·연차·휴가는 `날짜 + 내용` 줄, 일반 업무는 `[카테고리] 내용` 줄 (같은 내용은 한 줄로 합침)
  - `‹ ›`로 주 이동, `이번 주` 버튼, 복사 전에 내용 직접 수정 (저장되지 않음)
  - **엑셀 칸에 복사**: 여러 줄을 엑셀 칸 하나에 붙여넣도록 복사 / **텍스트 복사**: 그대로 복사
  - 완료한 일은 완료 상태로 남은 할 일과 완료 이력을 함께 사용 (연차·휴가는 완료 체크 없이 날짜만 맞으면 포함)

- **할 일 관리**
  - 할 일 추가 / 수정 / 삭제 (다중 줄 텍스트 입력 가능, Shift+Enter 지원)
  - 완료 체크 및 완료 항목 일괄 삭제 (완료 탭에서만 표시)
  - **업무 종류:** 일반 업무 / 정기 업무 / 연차·휴가 중 선택 (입력창·수정 폼·반복 일정에서 지정, 카드에 배지 표시). 연차·휴가는 날짜 필수·반복 불가. 옛 데이터는 일반 업무로 불러옴
  - 우선순위 설정 (높음 / 보통 / 낮음)
  - 카테고리 태그 (기존에 쓰던 카테고리를 태블릿/PC는 칩 제안, 모바일은 팝업 선택기로 골라서 입력 가능)
  - 할 일 카드에 등록일 · 마감일 표시
  - **할 일 고정(Pin):** 중요한 항목을 목록 최상단에 고정, 파란 테두리로 시각 강조
  - **다중 선택 일괄 처리:** 여러 할 일을 선택하여 카테고리, 우선순위를 일괄 변경하거나 삭제
  - **실행취소(Undo):** 항목 삭제 및 일괄 삭제 시 하단 토스트 알림을 통해 5초 내 복구 가능 (진행 바로 남은 시간 시각화)
  - **반복 일정 (반복 시리즈):** 매일 / 매주 / 매달 반복 규칙을 별도 데이터로 관리
    - 상단 툴바 **`🔁 반복 일정`** 메뉴에서 등록된 반복 규칙을 목록으로 확인 · 주기/기준일/제목/카테고리/우선순위/종료일 편집 · 종료 / 재개 / 삭제
    - **다음 예정일 미리보기:** 아직 생성되지 않은 앞으로의 회차 3개를 날짜로 표시
    - 각 회차는 이전 회차 완료 여부와 무관하게 **예정일이 되면 자동 생성** (한 번 놓쳐도 이후 회차가 누락되지 않음)
    - 오래 앱을 열지 않았다가 다시 열면 그 사이 놓친 회차를 소급 생성 (매일 반복은 최근 14일치까지)
    - 말일(29~31일) 기준 매월 반복은 해당 월에 그 날짜가 없으면 말일로 맞춤 (예: 1/31 → 2/28)
    - 기존 반복 할 일 데이터는 앱 첫 실행 시 반복 시리즈로 자동 전환

- **서브태스크 (하위 항목)**
  - 각 할 일에 세부 체크리스트 추가 / 수정 / 삭제
  - **드래그 핸들로 순서 변경** (네이티브 HTML5 DnD, 라이브러리 없음)
  - 진행도 배지 표시 (예: 2/4)
  - 모든 서브태스크 완료 시 상위 항목도 완료 처리
  - **개별/전체 접기·펴기:** 하위 항목을 항목별 또는 전체 목록 단위로 접어 리스트를 압축 표시 (접힘 상태는 새로고침 후에도 유지, 직접 정렬 시 편의성 향상)

- **필터 · 검색 · 정렬**
  - 상태 탭: **진행 중** (기본값) / 전체 / 완료
  - 마감일 범위: 전체 / 오늘 마감 / 이번 주 마감 / 지연
  - 카테고리별 필터
  - **반복 할 일만 보기:** 반복 시리즈에 속한 회차(또는 반복 주기가 설정된 할 일)만 모아서 확인
  - 실시간 텍스트 검색 (제목 · 카테고리)
  - 정렬: **직접 정렬(드래그 앤 드롭)** / 최신순 / 우선순위순 / 마감일순
  - 필터·정렬·검색 상태 새로고침 후 유지 (localStorage)

- **업무 편의성 (UX)**
  - 긴 목록 스크롤 시 화면 상단에 '할 일 추가창' 고정 (Sticky 기능)
  - **스크롤 탑 버튼:** 화면을 아래로 스크롤하면 나타나는 화면 상단 이동 버튼
  - **모바일/태블릿 반응형:** 필터 바 · 메모장 · 마감 요약 배너 세로 스택 배치, 할 일 입력창 상세 옵션(우선순위/마감일/카테고리/반복) 접기·펼치기 토글
  - **퀵 네비게이션:** 현재 할 일 목록을 좌측 사이드바로 표시, 클릭 시 해당 항목으로 스크롤
  - 마감일 설정, 오늘/이번주/지연 마감 요약 배너 알림
  - **마감일 브라우저 알림:** 앱 실행 시 하루 1회, 오늘 마감·지연 건수를 데스크탑 알림으로 안내 (설정에서 On/Off, 옵트인)
  - 다크모드/라이트모드 토글 지원
  - **올해 D-day:** 상단 툴바 왼쪽에 12월 31일까지 남은 날과 올해 진행률(%) 표시 (자정에 자동 갱신, 모바일은 D-day만 표시)
  - **홈 화면 설치(PWA):** 브라우저 탭이 아닌 독립 앱처럼 설치 가능, 인터넷 연결 없이도 실행

- **빠른 메모장**
  - 멀티 탭 생성 · 제목 편집 · 검색 지원, 자동 저장
  - 탭 고정(Pin) 기능으로 중요 메모 최상단 유지
  - 탭 드래그 앤 드롭으로 순서 변경, 새로고침 후에도 순서 유지
  - **할 일 ↔ 메모 다중 연결:** 할 일 하나에 메모를 여러 개 연결 가능, 수정 모드에서 체크박스로 선택, 메모장에서도 다중 연결·해제 가능, 카드에 연결된 메모 배지로 표시. 이미 연결된 카드에도 `+ 메모` 버튼이 항상 남아 있어 추가 연결 가능
  - 메모장 사이드바에 각 메모와 연결된 할 일 개수를 배지로 표시
  - 메모 제목 옆 클립보드 복사·공유·카카오톡 공유는 더보기(⋯) 메뉴로 통합
  - 연결된 할 일 체크리스트는 접기/펼치기 토글로 기본 접힘, 필요할 때만 펼쳐 공간 확보
  - 모바일에서는 검색·추가·목록을 토글 뒤로 접어 기본 노출을 최소화, 펼치면 목록이 남은 공간을 채우고 내용 영역은 숨겨져 목록에 집중 가능

- **공유 · 복사**
  - 할 일/메모를 **클립보드에 복사** (제목 + 하위 항목 체크리스트 텍스트, 완료 항목엔 ✔ 표시)
  - **공유:** Web Share API로 모바일에서 OS 공유 시트 호출, 미지원 환경은 클립보드 복사로 자동 대체
  - **카카오톡 공유:** 별도 팝업 없이 카카오톡 공유창으로 바로 전달
  - **복사(복제):** 할 일을 사본으로 만들어 바로 아래에 추가 (완료 상태 등은 초기화, 템플릿처럼 재사용) — 메모는 탭이 과밀해져 복제 기능 제외
  - 할 일 카드는 클립보드 복사·공유·카카오톡 공유·복사를 **더보기(⋯) 메뉴**로 묶어 액션 버튼 과밀 방지

- **완료 이력**
  - 완료 상태였던 할 일이 삭제될 때(개별 삭제·완료 항목 일괄 삭제 모두 포함) 제목·카테고리·우선순위·하위 항목·완료 시각을 영구 기록
  - 미완료 상태에서 삭제된 항목은 기록되지 않음
  - 날짜별로 그룹핑된 목록으로 조회, 카테고리 셀렉트박스·기간(시작일~종료일) 범위 선택·내용 텍스트 검색 지원
  - 항목별 또는 필터링된 전체 목록 기준으로 클립보드 복사·공유(Web Share)·카카오톡 공유 지원
  - 실행취소(Undo) 시 기록도 함께 원상복구
  - 잘못 기록된 항목은 휴지통 아이콘으로 하나만 삭제 가능 (확인 후 삭제, 복구 불가) / 전체 삭제는 하단 `이력 전체 삭제`

- **백업 · 설정**
  - 할 일 + 메모 + 완료 이력 + 반복 시리즈 데이터를 JSON 파일로 내보내기 / 가져오기 (결과를 색상으로 구분한 토스트 알림: 가져오기 파랑 / 내보내기 초록 / 실패 빨강)
  - **백업 알림:** 백업을 한 번도 안 했거나 마지막 백업이 7일 넘게 지났으면 화면 맨 위에 배너 표시 (`지금 내보내기` / `내일 다시 알림`), 설정 모달에서 마지막 백업 날짜 확인
  - 설정 모달에서 할 일 / 메모 / 완료 이력 / 전체 데이터 초기화

- **디자인 시스템**
  - Toss 앱 스타일 기반 UI (카드 그림자, 세그먼트 탭, 필 배지, 중립 색상)
  - `DESIGN.md` — 프로젝트 디자인 토큰·컴포넌트 스펙·Do&Don't 문서화

## 데이터 보호 정책
> **모든 데이터는 사용자의 브라우저 localStorage에만 저장되며, 저장소나 서버로 전송되지 않습니다.** 

## 로컬 실행 가이드 (Windows 사용자)
프로젝트 폴더 내에 있는 **`투두리스트_실행.bat`** 파일을 더블클릭하면 명령어를 입력할 필요 없이 자동으로 로컬 서버가 구동되고 투두리스트 웹 브라우저가 열립니다. (바탕화면에 바로가기를 만들어 사용하시면 편리합니다.)

## 개발자용 명령어

```bash
# 의존성 설치
npm install

# 로컬 개발 서버 실행
npm run dev

# 테스트 실행 (한 번) / 변경 감지 모드
npm run test
npm run test:watch

# 린트
npm run lint

# 프로덕션 빌드 (TypeScript 컴파일 포함)
npm run build
```

커밋 전에는 `npm run lint`, `npm run test`, `npm run build`가 모두 통과해야 합니다.

## 프로젝트 구조

```text
src/
├─ App.tsx              화면 조립, 백업 가져오기/내보내기, 토스트
├─ components/          UI 컴포넌트
│  ├─ TodoItem.tsx      할 일 카드 (편집 폼·하위 항목·더보기 메뉴는 TodoItem*.tsx로 분리)
│  ├─ *Modal.tsx        <dialog> 기반 모달들
│  └─ icons.tsx         인라인 SVG 아이콘
├─ hooks/               상태·동작 훅
│  ├─ useTodos.ts       할 일 상태, 필터·정렬, 실행취소, 완료 이력
│  ├─ useRecurrenceSeries.ts  반복 시리즈 상태와 회차 자동 생성
│  └─ useModalDialog / useDismiss / useDayChange / useSelection ...
```
